# QA Checklist — MY DISCIPLINE OS

## Awamu ya 1: Jaribio la manual
- [ ] Fungua `http://localhost:8000`; hakikisha dashboard inaonekana bila errors.
- [ ] Ongeza task yenye tarehe ya leo; refresh; thibitisha bado ipo.
- [ ] Hariri task; hakikisha mabadiliko yanahifadhiwa.
- [ ] Kamilisha task; hakikisha progress na XP vinabadilika mara moja.
- [ ] Jaribu kuweka MIT nne kwa siku moja; ya nne inapaswa kuzuiwa ikiwa tatu za kwanza bado hazijakamilika.
- [ ] Futa task; hakikisha confirmation inaonekana.
- [ ] Ongeza ratiba; ongeza nyingine inayogongana; thibitisha onyo linaonekana na mfumo haulazimishi kuhifadhi.
- [ ] Chagua tarehe nyingine kwenye calendar; thibitisha ratiba ya tarehe hiyo inaonekana.
- [ ] Badilisha theme; refresh; hakikisha theme inabaki.
- [ ] Anzisha focus timer, pause, resume, kisha rekodi session.
- [ ] Ongeza somo, rekodi study session na flashcard.
- [ ] Ongeza mradi active; jaribu kuanzisha active project ya pili; inapaswa kukataa.
- [ ] Rekodi mauzo ya mfano; thibitisha mapato/gharama zinaonekana.
- [ ] Fanya daily review; refresh; thibitisha tathmini ipo.
- [ ] Export JSON; reset test data; import backup; thibitisha rekodi zinarudi.
- [ ] Export tasks CSV na report CSV; fungua faili na uthibitishe data.
- [ ] Jaribu kwenye screen ya simu na keyboard.
- [ ] Kagua DevTools Console na Application > Service Workers kwenye localhost/HTTPS.
- [ ] Fanya backup kabla ya kujaribu reset kwenye data halisi.

## Supabase login na sync (baada ya kuweka URL/key na ku-run SQL)
- [ ] Tengeneza akaunti mpya, thibitisha email, ingia na utoke.
- [ ] Chagua kupakia data ya browser; thibitisha idadi ya records na settings kwenye Supabase.
- [ ] Ingia kwa akaunti hiyo kwenye kifaa/browser ya pili; thibitisha data inaonekana.
- [ ] Badilisha task kwenye kifaa kimoja; hakikisha kifaa kingine kinaipokea bila refresh.
- [ ] Fanya mabadiliko kwenye vifaa viwili wakati wa offline/online; thibitisha prompt ya kuchagua inaonekana badala ya kufuta data kimyakimya.
- [ ] Tumia akaunti ya pili; hakikisha RLS hairuhusu kuona workspace ya akaunti ya kwanza.
- [ ] Katisha internet, hifadhi mabadiliko, re-connect; thibitisha sync na backup export.

## Maelezo ya QA
Checklist hii ni mpango wa majaribio, si madai kwamba kila jaribio limeendeshwa kwenye kifaa cha mwisho. MVP imeundwa kwa interactions halisi; uthibitishaji wa cross-browser na PWA unahitaji kujaribiwa katika mazingira ya deployment.
